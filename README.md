# Gitea history for evilnkode

Use this archive to read pull requests and issues imported from Gitea, including their descriptions, authors, timestamps, comments, and reviews. Source text is preserved as historical content.

Original repository: https://gitea.donovankelly.xyz/dkelly/evilnkode

The default branch contains the application code. This separate `gitea-history` branch contains the discussion archive. Open pull requests are also recreated on GitHub where their branches still have changes to merge.

Git commits retain their original authors and timestamps. GitHub pull-request numbers, creation dates, review approvals, and authorship are not imported as native historical events; the records here preserve that information.

Source pull-request commit refs are stored under `refs/gitea/pull/NUMBER/head`. A mirror clone includes those refs.


## Source settings

See [source settings](source-settings.json) for Gitea branch rules, collaborator identities, and CI secret names. Secret values are unavailable through the Gitea API. Gitea identities require an explicit GitHub account mapping before invitations can be sent.
